# Guion orientativo de presentación — máximo 10 minutos

**Personalizar con los nombres verdaderos de los integrantes.** Todos deben aparecer
al menos **1 minuto** en el video, aunque hablen simultáneamente.

| Tiempo | Responsable | Mostrar en pantalla |
|---|---|---|
| 0:00–1:00 | Integrante 1 | Problema y objetivo; diagrama con 3 backends |
| 1:00–2:20 | Integrante 1 | Docker Compose, red y volúmenes |
| 2:20–3:40 | Integrante 2 | Dockerfile, aplicación Flask y `/metrics` |
| 3:40–4:50 | Integrante 2 | Nginx y balanceo: alternar 3 instancias |
| 4:50–6:10 | Integrante 3 | Prometheus: 6 targets UP, consultas PromQL |
| 6:10–7:20 | Integrante 3 | Dashboard Grafana, CPU y latencia |
| 7:20–8:30 | Equipo | Ejecutar k6, resultados reales y gráficas |
| 8:30–9:25 | Equipo | Apagar app1, comprobar continuidad, recuperarlo |
| 9:25–9:50 | Equipo | Conclusiones, limitaciones, enlaces de GitHub |

Si el grupo tiene 1, 2 o más de 3 integrantes, redistribuye los segmentos para que
**cada integrante aparezca al menos un minuto** y el video no supere 10 minutos.
No muestres resultados inventados; graba el funcionamiento real del proyecto.
